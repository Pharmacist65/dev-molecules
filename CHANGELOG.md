# Changelog

## 0.1.0 — Public Vertical Slice — 2026-08-22

### Included

- five-mode TR/EN product shell;
- source-labelled 2D/3D Explore with one shared WebGL scene;
- 15 seed identities with explicit PubChem and Drugs@FDA provenance boundaries;
- three non-operational, patent-anchored synthesis learning stories;
- ten-topic curated nomenclature lab, deterministic feedback, and versioned device-local learning progress;
- fail-closed curated Discover cards;
- server-capable and static GitHub Pages delivery adapters;
- typecheck, lint, dependency audit, Node, browser, and Pages deployment gates.

### Explicit boundaries

- The seed catalog is not the full approved-small-molecule universe.
- Synthesis stories and nomenclature exercises are educational drafts pending named expert review.
- Nomenclature is a curated learning engine, not a universal structure-to-IUPAC naming service.
- Discover is not an analog-search, RAG, docking, synthesis-planning, or autonomous discovery system.
- No institution backend, durable multi-user store, or general-purpose chemical editor is included.
- No open-source project license has been declared, and source-data redistribution review remains open.
