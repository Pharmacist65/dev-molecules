# Türkçe kimya terminolojisi

Bu sözlük Student ve Expert arayüzlerinde kullanılan temel terimleri sabitler. Sistematik IUPAC adları, SMILES, InChIKey, formüller, veri tabanı adları ve kaynak belge başlıkları çevrilmez.

| English | Türkçe | Kullanım notu |
| --- | --- | --- |
| absorption | emilim | “absorpsiyon” yalnız kaynak başlığında korunur. |
| active moiety | aktif moleküler kısım | Ürün veya tuz ile karıştırılmaz. |
| active metabolite | aktif metabolit | Yalnız doğrudan kaynak varsa gösterilir. |
| adverse effect | istenmeyen etki | “yan etki” günlük dil alternatifi olabilir. |
| agonist | agonist | Etkileşim türü; hedef veya assay bağlamıyla gösterilir. |
| antagonist | antagonist | Etkileşim türü; hedef veya assay bağlamıyla gösterilir. |
| aromatic ring | aromatik halka | “aromatik” koku anlamında kullanılmaz. |
| assay | deney sistemi | Expert yüzeyinde “assay” kaynak terimi parantez içinde korunabilir. |
| bioavailability | biyoyararlanım | Route/form koşulu olmadan sayısal değer gösterilmez. |
| bond | bağ | Tekli, çiftli ve üçlü bağ. |
| bridged ring | köprülü halka | “bridged system” → “köprülü halka sistemi”. |
| clearance | klerens | Birim ve koşul zorunludur. |
| computed | hesaplanmış | Deneysel değerle aynı etiket altında birleştirilmez. |
| distribution | dağılım | ADME bağlamı. |
| drug journey | vücuttaki yolculuk | Moleküler mekanizma ile terapötik sonuç ayrılır. |
| electrophile | elektrofil | Mekanizma dersi terimi. |
| elimination half-life | eliminasyon yarı ömrü | Route/form ve kaynak bağlamı korunur. |
| excretion | atılım | Metabolizma ile aynı aşama değildir. |
| experimental | deneysel | Kaynağı ve ölçüm koşulu görünür olmalıdır. |
| formal charge | biçimsel yük | “formal yük” ikincil kabul edilir. |
| functional group | fonksiyonel grup | Hesaplanmış motif önerileri doğrulanmış grup gibi sunulmaz. |
| fused ring | kaynaşık halka | “füze halka” kullanımı yasaktır. |
| inhibitor | inhibitör | Etkileşim türü; nicel değer yoksa ölçülmüş güç iddiası yapılmaz. |
| leaving group | ayrılan grup | Mekanizma dersi terimi. |
| mechanism of action | etki mekanizması | Farmakolojik etki ile klinik sonuç ayrılır. |
| metabolism | metabolizma | Metabolit bağlantıları enzim ve kaynakla gösterilir. |
| molecular target | moleküler hedef | Dekoratif bağlanma görseli docking sonucu sayılmaz. |
| nucleophile | nükleofil | Mekanizma dersi terimi. |
| parent molecule | ana molekül | Tuz, ester, hidrat ve solvat ilişkilerinde kullanılır. |
| pharmacodynamics | farmakodinami | Hedef/yolak etkileri. |
| pharmacokinetics | farmakokinetik | Emilim, dağılım, metabolizma ve atılım ölçümleri. |
| scaffold | moleküler iskelet | Gerekirse ilk kullanımda “scaffold (moleküler iskelet)”. |
| selectivity | seçicilik | Yalnız karşılaştırılabilir assay koşullarında karşılaştırılır. |
| solvate | solvat | Kimyasal form ilişkisi. |
| spiro system | spiro halka sistemi | “spiro” korunur. |
| stereocenter | stereomerkez | R/S ataması doğrulanmadan kesin kimlik iddiası yapılmaz. |
| target family | hedef ailesi | Protein ailesi; terapötik sınıf değildir. |
| teaching route | eğitim rotası | Bildirilmiş rota etiketiyle sunulmaz. |
| therapeutic class | terapötik sınıf | Farmakolojik mekanizma ve kimyasal aileden ayrı tutulur. |
| volume of distribution | dağılım hacmi | Birim ve hasta/deney koşulu zorunludur. |

## Yasaklı sızıntılar

Student arayüzünde `source-supported`, `pending-review`, `computed-unreviewed`, `literature-reported`, `not-assessed` ve benzeri ham enum değerleri gösterilmez. Bu değerler her zaman yerelleştirilmiş sunum katmanından geçer.
