## Shipping gate

The executable gate is in
`lib/domain/capabilities/feature-readiness.ts`. It produces `shipped` only when
all four evidence classes are present. It also rejects unfinished primary-nav
routes, empty placeholders, and enabled planned-only flags. Contract-only rows
above remain `partial` by design.
