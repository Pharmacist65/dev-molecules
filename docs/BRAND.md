# Molevren — Brand contract

## Public identity

- Product name: **Molevren**
- Interface wordmark: **MOL·EVREN**
- English descriptor: **A source-aware molecular learning platform**
- Turkish descriptor: **Kaynaklara dayanan moleküler öğrenme platformu**
- English campaign line: **From the page into molecular space.**
- Turkish campaign line: **Sayfadan moleküler uzama.**

The name combines `mol` with the Turkish word `evren` (universe). Public copy uses
`Molevren` in prose and `MOL·EVREN` only as the visual wordmark.

## Scientific positioning

Molevren is a bilingual visual learning and evidence-exploration environment. The
brand must not imply autonomous drug discovery, novelty, patentability, efficacy,
safety, regulatory approval, laboratory reproducibility, or synthesizability.

Preferred framing:

- see molecular form;
- follow resolvable sources and review state;
- learn, compare, and ask better questions;
- keep educational, predicted, pending, conflicting, and verified states distinct.

## Stable technical identifiers

The current GitHub repository and Pages deployment still use the historical
`dev-molecules` slug. Existing local-storage keys, source IDs, API headers, public
asset base paths, and deployed URLs retain that slug until an explicit migration is
planned. They are technical compatibility identifiers, not the public product name.
