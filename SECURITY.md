# Security policy

Dev Molecules is an educational software project. It is not a clinical decision-support system and it must not receive patient data, credentials, private molecular structures, or unpublished research material through public issue reports.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting feature for this repository. Include the affected revision, a minimal reproduction, expected impact, and any safe mitigation you have tested. Do not open a public issue for a vulnerability that could expose data, secrets, or deployment infrastructure.

## Supported version

Security fixes target the latest commit on `main`. No earlier revision is currently maintained as a supported release branch.

## Scientific integrity is part of safety

Reports are also welcome for provenance loss, predicted content presented as verified, unsafe operational synthesis detail, identity/form conflation, or any path that turns missing evidence into novelty, efficacy, patentability, or synthesizability claims.
